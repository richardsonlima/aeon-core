The `aeon` command uses only the standard library. Every command that prints data accepts `--json`. Expected failures print a message and a fix hint and exit non-zero; they never print a stack trace. Exit codes: `0` ok, `1` failure (including a failed `--strict` campaign or a broken audit chain), `2` usage error.
